# Password Manager Backend

Backend часть корпоративного менеджера паролей с клиентским шифрованием.


## Возможности

- регистрация и авторизация пользователей;

- хранение записей в зашифрованном виде;

- управление пользователями;

- управление департаментами;

- управление ролями;

- персональный доступ к записям;

- ролевой доступ к записям;

- REST API;

- модульная архитектура (Spring Modulith).

---

## Технологии

- Java 21

- Spring Boot 3

- Spring Security

- Spring Modulith

- Spring Data JPA

- Hibernate

- PostgreSQL

- Docker

- Maven

---

## Архитектура

Проект разделен на независимые модули.

Взаимодействие между модулями осуществляется через публичные API, предоставляемые каждым модулем.

---

## Безопасность

Особенность проекта заключается в том, что сервер **не имеет доступа к открытым паролям пользователей**.

Backend хранит только:

- зашифрованные записи;

- зашифрованные ключи записей;

- публичные ключи пользователей;

- зашифрованные приватные ключи.

Все криптографические операции выполняются на стороне клиента.

# Запуск проекта

## Требования

- Java 21

- Docker Desktop

---

### 1. Запустить PostgreSQL

В корне проекта выполнить

```bash

docker compose up -d

```

После запуска будет автоматически создан контейнер PostgreSQL.

---

### 2. Запустить приложение

```bash

./mvnw spring-boot:run

```

или

```bash

mvn spring-boot:run

```

---

## Сборка

```bash

./mvnw clean package

```
